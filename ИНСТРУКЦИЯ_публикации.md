# Мониторинг выбросов — публикация Streamlit

## Структура
- `app.py` — готовое Streamlit-приложение
- `requirements.txt` — необходимые библиотеки
- `vkr_output/*.csv` — подготовленные данные за 2019–2025 годы

## Публикация
1. Распакуйте этот архив.
2. На https://github.com создайте **публичный** репозиторий (например, `buryatia-air-monitoring`).
3. Через `Add file → Upload files` загрузите `app.py`, `requirements.txt` и **папку** `vkr_output` со всеми CSV. Убедитесь, что папка не потеряна.
4. Нажмите `Commit changes`.
5. Откройте https://share.streamlit.io и войдите через GitHub.
6. Нажмите `Create app → Yup, I have an app`, выберите репозиторий и ветку `main`.
7. В поле `Main file path` укажите `app.py`, затем `Deploy`.
8. После публикации проверьте URL вида `https://<имя>.streamlit.app` в браузере без авторизации.

**Важно:** файл `app.py` требует папку `vkr_output` рядом с собой. Не загружайте 63-МБ архив исходных данных: они уже преобразованы в CSV. Не публикуйте личные/закрытые файлы в открытом репозитории.

## Локальный запуск (необязательно)
```bash
pip install -r requirements.txt
streamlit run app.py
```

Исходный официальный раздел: https://rpn.gov.ru/open-service/analytic-data/statistic-reports/air-protect/
